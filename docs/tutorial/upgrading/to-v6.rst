Guide: Upgrading DSMR-reader v5.x to v6.x
=========================================

DSMR-reader ``v6.x`` is backwards incompatible with ``5.x``. You will have to manually upgrade to make sure it will run properly.

DSMR-reader v6 will be released in **January 2026** and the documentation (including how to upgrade) will then be available here:

- `DSMR-reader v6 documentation <https://dsmr-reader.readthedocs.io/en/v6/>`_
