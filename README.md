# DSMR-reader
Self-hosted DSMR-protocol reader, telegram data storage and energy consumption visualizer.
Can be used for reading the smart meter DSMR (Dutch Smart Meter Requirements) P1 port yourself at your home. 


## Prerequisites
You will need hardware that can run Linux software and a cable (or other connection) to your smart meter.
